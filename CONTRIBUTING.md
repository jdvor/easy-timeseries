## How to Contribute

### Reporting Bugs

Open a GitHub Issue describing:
- What you expected to happen
- What actually happened
- Steps to reproduce the issue
- Your environment (OS, language/runtime version, etc.)

### Suggesting Features

Open a GitHub Issue with the `enhancement` label. Describe the use case and why you think it belongs in the project.

### Submitting a Pull Request

1. Fork the repository and create a branch from `master`.
2. Make your changes. Keep commits focused and descriptive.
3. If applicable, add or update tests.
4. Update documentation or the README if your change affects public-facing behavior.
5. Open a pull request with a clear title and description of what you have changed and why.

## Code Style

Please follow the existing code style and conventions present in the project. Consistency is preferred over personal preference.

## Attribution

Contributors will not be listed as co-authors of the project by default, but significant contributions may be acknowledged in a `CONTRIBUTORS` file or in release notes at the author's discretion.
