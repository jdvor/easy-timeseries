# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities. Public disclosure before a fix is available puts other users at risk.

Instead, report vulnerabilities privately by emailing:

**Jan Dvořák** — <github.mandarin334@passmail.com>

Include as much detail as you can:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof of concept
- Affected versions, if known

## What to Expect

- Vulnerabilities will be assessed and addressed as promptly as possible.
- You will be kept informed of the progress toward a fix.
- Once resolved, the fix will be released and the vulnerability disclosed publicly, with credit given to the reporter unless you prefer to remain anonymous.

## Scope

This policy covers the source code in this repository. It does not cover third-party dependencies — please report those directly to their respective maintainers.
